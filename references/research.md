# 调研方法（阶段 ①）

调研只为回答一个问题：**这次发布用什么角度，验证哪一条假设？**
普通的调研报告止于「用户怎么说」；这里要多走一步，得出一个可以被发布后的数据证伪的决定。

## 1. 搜索词矩阵

`research.py keywords` 给出基础矩阵，你再按下面的维度补充到 8 到 15 个词：

| 维度 | 目的 | 例 |
|---|---|---|
| 品类基础 | 看整体供给 | 咖啡液 推荐 / 测评 / 怎么选 |
| 反面 | 看真实痛点 | 避雷 / 踩坑 / 缺点 / 后悔 |
| 教程用法 | 看使用门槛 | 教程 / 怎么用 / 新手 |
| 对比平替 | 看决策逻辑 | A vs B / 平替 |
| 人群场景 | 找细分入口 | 学生党 咖啡液 / 出差 咖啡 |
| 竞品 | 每个竞品单独搜，重点看评论区 | 竞品名 / 竞品名 缺点 |
| 痛点直搜 | 验证缺口是否真的没人写 | 咖啡液 太苦 |
| 同义词与黑话 | 脚本给不出，由你补充 | 冷萃液 / 浓缩咖啡液 / 咖啡胶囊 |

每个词建议各取「综合」和「最新」排序的前 10 到 20 篇。只看综合排序会被老爆款占满。

## 2. 数据从哪来

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 环境里已有的小红书搜索工具 | 直接调用并把结果存成 json。本技能不安装抓取程序、不要账号 Cookie：自动化访问有账号风险，决定权在用户。 |
| 2 | 联网搜索 | 补充站外测评、吐槽、竞品官方信息。写入结论时注明「站外」。 |
| 3 | 用户粘贴、表格、截图 | 始终可用。截图由你转成每行一篇的文本。 |

`research.py add` 接受：

- **json / jsonl**：自动在嵌套结构里找标题、点赞、收藏、评论、粉丝、时间、链接、评论列表等字段，兼容常见工具的导出。
- **csv**：表头用中文或英文均可（标题、点赞数、收藏数、评论数、粉丝数、发布时间、链接）。
- **txt / md**：每行一篇，`标题 | 赞 1.2万 | 藏 800 | 评 56 | 粉丝 900 | 2026-11-01 | 链接`，字段可缺，支持「万 / w / k」。

**粉丝数很重要**：有了它才能算赞粉比、识别低粉爆款。拿不到时脚本会退回「互动 + 时效」评分并提示。

## 3. 读懂分析结果

| 部分 | 怎么读 | 常见误读 |
|---|---|---|
| 角度供给 | 「供给少互动高」是机会；占比最高的角度是红海 | 篇数少于 2 的角度不算机会，可能只是偶然 |
| 标题钩子提升度 | 大于 1.3 倍值得试；两边各少于 5 篇不计算 | 这是相关不是因果，所以才要作为假设去验证 |
| 需求缺口 | 评论提及不少于 3 条、标题回应的笔记不超过 10% | 缺口也可能是「没人关心」，用痛点直搜的结果复核 |
| 低粉爆款 | 粉丝少于 5000 且赞过千，或赞粉比不低于 1 | 大号的爆款不要模仿，那是账号的功劳 |
| 综合评分 | 互动分位 40% + 时效 25% + 赞粉比 35% | 分数只用于排序，不是质量结论 |

互动 = 赞 + 2×藏 + 3×评。全部用中位数而不是平均数，避免被单篇大爆款带偏。

## 4. 拆解对标笔记

对低粉爆款 Top 3 到 5 篇，逐篇记录（需要正文；没有就请用户粘贴）：

```
标题用了什么钩子：
前两行怎么开头（痛点 / 结果 / 反差 / 提问）：
正文结构（步骤 / 清单 / 对比 / 故事）：
有没有写缺点：
结尾怎么引导评论：
评论区最高赞在说什么：
我能照做的一点：
我要做得不一样的一点：
```

## 5. 写发布假设

格式：**「对 [人群]，用 [角度/写法] 会比 [对照] 的 [指标] 更高」**。

- 好：对早八打工人，用价格痛点开头会比泛卖点开头的评论率更高。
- 坏：这篇会火。（无法证伪）

一次只验证一个变量：角度、标题、封面、形式四选一。已被证伪的不再重复（见 `launch_log.py next`）。

## 6. 发布简报模板

```
产品 / 目标人群：
调研样本：N 篇笔记，M 条评论，时间窗，覆盖的搜索词
本次角度：                （依据：角度供给表第几行）
要回应的缺口：            （依据：哪些评论原话）
对标笔记：                （链接，学什么、不学什么）
发布假设：
主指标：点击率 / 互动率 / 收藏点赞比 / 评论率（选一个）
形式：图文 / 视频
不确定的地方：            （样本不足、缺粉丝数、推测）
```

## 7. 证据规则

- 数字来自脚本，观点指向笔记链接或评论原话。写完回读一遍，删掉没有来源的句子。
- 评论区比正文可信；高互动笔记里可能有推广，用评论区交叉验证。
- 样本不足 20 篇、评论不足 20 条时，结论降级为「线索」。
- 观点矛盾时两边都列，不替用户抹平分歧。
