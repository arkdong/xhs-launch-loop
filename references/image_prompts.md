# 配图提示词（阶段 ②）

`content_plan.py prompts` 按发布方案逐页生成提示词。这里说明规则，以及你在填写方案时怎样写出好的「画面」。

## 1. 先决定哪些页用实拍

| 情况 | 做法 |
|---|---|
| 产品外观、使用过程、成品效果 | **优先实拍**。AI 画的产品和实物不一样，会被评论区质疑。把页码写进方案的 `real_photo_pages`，脚本会输出拍摄要求而不是提示词。 |
| 有实拍但背景乱 | 用图生图或只换背景，把实拍作为参考图。 |
| 场景氛围、痛点情境、信息卡片、对比表、步骤示意 | 适合 AI 生成。 |

使用了 AI 生成图片的笔记，发布时要在小红书发布页勾选内容含 AI 合成的声明。

## 2. 一条提示词的结构

```
[这一页的画面] + [画面中的产品，全系列同一句] + [构图] + [风格] + [配色，全系列同一组] + [比例与清晰度] + [是否出字]
```

- **画面**（你来写）：写看得见的东西，不写抽象概念。「办公桌上一杯冰拿铁，旁边一条咖啡液和几枚硬币」可以画；「高性价比的感觉」画不出来。
- **产品描述**：只写客观外观（颜色、形状、材质、尺寸），所有出现产品的图用同一句，保证产品长得一样。不出现产品的页把 `product_in_frame` 设为 false。
- **构图**：模板已给出，可按内容修改。封面固定「主体居中偏下，上方三分之一留白」。
- **配色**：2 到 3 个主色，全系列一致，翻页时才像一套。
- **比例**：图文 3:4（1242×1660），视频封面与分镜 9:16（1080×1920）。

## 3. 文字怎么上图

默认**图里不出字**，提示词会要求留白，再用修图或排版工具加字。原因：多数生图模型写中文容易出错别字，而错字的封面比没有字更糟。

确认所用模型能稳定渲染中文时，加 `--with-text`，提示词会把要出现的文字用引号写明。生成后必须逐字核对。

图上文字的规则：封面不超过 12 字，只放一个信息点；其他页不超过 40 字；与标题互补而不是重复。

## 4. 风格预设

| 风格 | 适合 |
|---|---|
| 实拍生活感 | 种草、测评、个人体验。默认值，最像真人发的。 |
| 知识卡片 | 教程步骤、对比表、清单、缺点说明。信息卡片页会自动使用。 |
| 手绘插画 | 科普、故事、情绪类内容，或不方便拍摄的场景。 |
| 产品特写 | 新品首发的主视觉。 |
| 对比拼图 | 使用前后、A 与 B 的差异。 |

## 5. 交付给用户

- 当前环境能生图时：按提示词逐页生成，先出封面给用户确认风格，再出其余各页；每张图对照方案检查是否与产品实物相符。
- 不能生图时：把 `xhs_launch/plans/<编号>_prompts.md` 的内容交给用户，告诉他复制到自己的生图工具；需要英文时由你逐条翻译。
- 不生成：真实名人肖像、他人品牌商标、竞品包装、虚假的使用前后对比、伪造的数据截图或聊天记录。
