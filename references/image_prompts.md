# 配图提示词（阶段 ②）

`content_plan.py prompts` 按发布方案逐页生成提示词。这里说明规则，以及填写方案时怎样写出好的「画面」。

## 1. 先决定哪些页用实拍

原则：**产品外观以实拍为准。** AI 画出来的产品和实物总有出入，读者收到货会觉得被骗，评论区也会质疑。

| 情况 | 做法 |
|---|---|
| 有实拍素材 | 封面和产品特写用实拍：把页码写进方案的 `image.real_photo_pages`（例如 `[1, 3]`）。这些页输出的是拍摄要求，可以直接照着拍；另附一条可选的「只生成背景」提示词，里面只有场景，不提产品 |
| 有实拍，但用户想要 AI 做的封面 | 两条路，产品本身都来自实拍：① 用实拍做参考图（图生图），让 AI 只改光线和场景；② 用那条背景提示词生成不含产品的背景，再把实拍抠图叠上去。页码仍然留在 `real_photo_pages` 里 |
| 没有任何实拍 | 先向用户要产品外观（颜色、形状、材质、尺寸）或一张照片，写进 `image.subject`。不能猜，也不能留「待补充」，`check` 会拦下。生成后请用户对照实物，差得多的不要用 |
| 场景氛围、痛点情境、对比表、步骤示意 | 适合 AI 生成。画面里没有产品的页，把 `product_in_frame` 设为 false |
| 文字为主的卡片（结论、缺点、清单） | 用小红书发布页的文字模板或任何排版工具做最快。脚本另给一条只生成底图的提示词，底图上不出字，字后期加 |

`check` 会提醒两种矛盾：档案里写着有实拍素材，却没有任何一页标为实拍；档案里写着没有素材，却有页码标了实拍。

`prompts` 的输出开头会列出这一篇要准备什么：实拍几张、卡片几张、AI 生成几张，各在第几页。把这一行转告用户，他就知道自己要拍什么、做什么。

用了 AI 生成的图片，发布时在小红书发布页勾选内容含 AI 合成的声明。

## 2. 一条提示词的结构

```
[这一页的画面] + [画面中的产品，全系列同一句] + [构图] + [风格] + [配色，全系列同一组] + [比例与清晰度] + [是否出字]
```

- **画面**（你来写）：写看得见的东西，不写抽象概念。「办公桌上一杯冰拿铁，旁边一条咖啡液和几枚硬币」可以画；「高性价比的感觉」画不出来。实拍页的画面同时是拍摄要求，先写场景、再写产品放在哪（「办公桌上，键盘旁边放着护手霜」）：只生成背景的提示词只取场景那一半。卡片页的画面不要写「中间一行大字写结论」这类话，要出现的字写在 `text` 里。
- **产品描述**（`image.subject`）：只写客观外观，所有出现产品的图用同一句，保证产品长得一样。
- **构图**：模板已给出，可以按内容改。封面固定「主体居中偏下，上方三分之一留白」。
- **配色**（`image.palette`）：2 到 3 个主色，全系列一致，翻页时才像一套。
- **品牌角标**（`image.brand_tag`）：每张图顶部固定出现的账号名或产品名，可选。
- **比例**：图文 3:4（1242×1660），视频封面与分镜 9:16（1080×1920）。

新方案会自动沿用上一份方案的产品描述、配色、角标和风格，保证同一个账号的图像一套。

## 3. 文字怎么上图

默认**图里不出字**，提示词会要求留白，再用修图或排版工具加字。原因：多数生图模型写中文容易出错别字，而错字的封面比没有字更糟。

确认所用模型能稳定渲染中文时，加 `--with-text`，提示词会把要出现的文字用引号写明。生成后必须逐字核对。

图上文字的规则：封面不超过 12 字，只放一个信息点；其他页不超过 40 字；与标题互补而不是重复。

## 4. 风格预设

| 风格 | 适合 |
|---|---|
| 实拍生活感 | 种草、测评、个人体验。默认值，最像真人发的 |
| 知识卡片 | 教程步骤、对比表、清单、缺点说明。信息卡片页会自动使用 |
| 手绘插画 | 科普、故事、情绪类内容，或不方便拍摄的场景 |
| 产品特写 | 新品首发的主视觉 |
| 对比拼图 | 使用前后、A 与 B 的差异 |

用 `content_plan.py new --style 风格名` 指定，`content_plan.py templates` 查看全部。

## 5. 交付给用户

- 当前环境能生图：按提示词逐页生成，先出封面给用户确认风格，再出其余各页；每张图对照方案检查是否与产品实物相符。
- 不能生图：把 `xhs_launch/plans/<编号>_prompts.md` 交给用户，复制到自己的生图工具即可；对方的工具需要英文时，由你逐条翻译。
- 不生成：真实名人肖像、他人的品牌商标、竞品包装、虚假的使用前后对比、伪造的数据截图或聊天记录。
