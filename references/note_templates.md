# 笔记模板（阶段 ②）

平台限制：标题不超过 20 字，正文不超过 1000 字，话题标签 3 到 10 个。写完必须跑 `note_check.py`。

## 标题：一次给 3 个，分别用不同钩子

| 钩子 | 公式 | 例 |
|---|---|---|
| 人群 + 场景 | 人群｜场景下的结果 | 打工人早八续命｜3秒冷萃实测一周 |
| 数字 + 结果 | 数字 + 动作 + 结果 | 喝了 7 天，每天多睡 10 分钟 |
| 反差 / 避雷 | 以为…结果… | 以为是智商税，结果回购了 |
| 疑问 | 用户原话当标题 | 冷水真的能溶开吗？ |

## 正文结构

### A. 发布体（新品、新功能首发）
1. 开头一句：用户原话或具体场景的痛点（30 字内）
2. 我做了什么 / 这是什么：一句话
3. 三个要点：每点一行，带具体数字
4. 缺点或不适合的人：至少一条，这是可信度的来源
5. 结尾提问：一个容易回答的具体问题

### B. 种草体（真实体验）
场景 → 用之前 → 用之后 → 细节（价格、时长、次数）→ 缺点 → 提问

### C. 教程体（评论区求教程时）
结果图描述 → 准备清单 → 步骤 1 2 3 → 常见翻车点 → 提问

### D. 答疑体（评论区高频问题）
「上篇很多人问…」→ 逐条问答（直接引用评论）→ 还想知道什么

### E. 复盘体（公开迭代过程）
上次发了什么 → 收到什么反馈（引用评论）→ 我们改了什么 → 接下来

## 其他产出

- **封面文字**：不超过 12 字，大字只放一个信息点，与标题不重复。
- **话题标签**：品类词 2 个 + 场景词 1 到 2 个 + 人群词 1 个。
- **首评引导**：作者自己发的第一条评论，补充购买方式或抛出问题。

## 像真人写的

- 用「我」，写具体时间地点和数字，短句，口语。
- 保留一点不完美：缺点、犹豫、翻车。
- 不用：综上所述、总而言之、赋能、众所周知、不仅如此。
- 表情符号用于分点即可，每段不超过 2 个。
