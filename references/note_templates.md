# 写作模板（阶段 ②）

填写发布方案时照这里写。为什么这样写、依据是什么，见 `content_rules.md`。

平台限制：标题不超过 20 字，正文不超过 1000 字，话题标签 3 到 10 个。`content_plan.py check` 会检查。

## 标题：一次给 3 个，写法各不相同

调研里标为「可用」的钩子优先用；没有调研时从下面选三种。

| 写法 | 公式 | 例 |
|---|---|---|
| 人群 + 场景 | 人群在某个场景下的结果 | 打工人早八续命，3秒冷萃实测一周 |
| 数字 + 结果 | 数字 + 动作 + 结果 | 喝了 7 天，每天少排队 15 分钟 |
| 反差 | 以为…结果… | 以为是智商税，结果回购了 |
| 疑问 | 用户原话当标题 | 冷水真的能溶开吗？ |
| 新闻 | 把「上线、发布、开启」放在最前面 | 新口味上线：拿铁味来了 |

不要用期数、编号开头，标题里不放表情符号。

## 正文结构

方案里的 `body` 已经分好了段，每一段的 `guide` 写着该填什么。最后一段必须有一个问句，`check` 会查。

**通用五段**（发布体、测评实测、教程攻略、对比平替、答疑科普、避雷踩坑、清单合集、个人故事）

1. 开头钩子：用户原话或一个具体场景，30 字内。
2. 我为什么能说：真实使用时长，以及你和产品的关系。
3. 正文要点：和各页一一对应，每点一行，带具体数字。
4. 缺点与适合谁：至少一条缺点。这是可信度的来源。
5. 结尾提问：一个容易回答的具体问题。

「开头钩子」和「正文要点」按模板这样写：

| 模板 | 开头钩子 | 正文要点 |
|---|---|---|
| 发布体 | 痛点场景或用户原话 | 每页一个事实，带数字 |
| 测评实测、个人故事 | 一句话结论，或当时的状态 | 用之前 → 用之后 → 细节（价格、时长、次数） |
| 教程攻略 | 成品什么样 | 准备清单 → 步骤 1 2 3 → 常见翻车点 |
| 答疑科普 | 「上篇很多人问…」加一句话答案 | 逐条问答，直接引用评论原话 |
| 对比平替、避雷踩坑、清单合集 | 结论先行 | 逐条对比、逐个坑或逐个条目，每条带数字，最后说怎么选 |

**自带分段的模板**

| 模板 | 分段 |
|---|---|
| 上线公告 | 开头钩子 → 是什么（两行）→ 怎么参与（📅 时间 ✅ 方式）→ 回报与限制（🎁 带数字 ⚠️ 不算数的情况）→ 结尾提问 |
| 征集互动 | 开头钩子 → 征集什么（给一个示例）→ 怎么参与 → 回报与规则 → 结尾提问（把征集的要求再问一遍） |
| 结果公布 | 开头钩子（带总数字）→ 亮点（点名参与者、注明来源）→ 我们改了什么 → 接下来 → 结尾提问 |
| 深度长文 | 导读（三行）→ 我为什么能说 → 要点摘要（300 到 600 字，细节放图里）→ 局限 → 结尾提问 |
| 情绪短片 | 一句话（60 到 70 字，只补画面里没说的）→ 结尾提问 |

各模板的页面结构用 `content_plan.py templates` 查看。

## 「我为什么能说」怎么写

这一句同时交代使用经历和身份。身份照档案里的如实写：

| 身份 | 例 |
|---|---|
| 品牌方、店主 | 「自家产品，团队 5 个人连喝了 7 天，把账算给你看。」 |
| 员工 | 「我在这个品牌做产品，这款我自己用了一个月。」 |
| 自己买的用户 | 「自己买的，用到第二支了。」 |
| 收了报酬或样品 | 「品牌送测，用了两周，下面是真实感受。」 |

没有这一段的模板（上线公告、征集互动、结果公布、情绪短片），把身份写进开头或「是什么」那一段。

## 其他内容

- **封面文字**：不超过 12 字，只放一个信息点，和标题互补而不是重复。
- **每页文字**：一页只讲一件事，普通页不超过 40 字。
- **画面**（`visual`）：写看得见的东西，例如「办公桌上一杯冰拿铁，旁边一条咖啡液和几枚硬币」，不写「高性价比的感觉」。
- **话题标签**：品类词 2 个 + 场景词 1 到 2 个 + 人群词 1 个；固定的账号标签放 `fixed_tags`。
- **首评**：作者自己发的第一条评论，补充站内购买方式，或再抛一个问题。

## 像真人写的

- 用「我」，写具体的时间、地点和数字，短句，口语。
- 保留一点不完美：缺点、犹豫、翻车。
- 不用：综上所述、总而言之、赋能、众所周知、不仅如此。
- 表情符号只当分点符号，每段不超过 2 个。
- 所有事实来自产品档案。档案里没有的数字不要写，去问用户。
