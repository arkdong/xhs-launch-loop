# 合规与发布前检查规则

`note_check.py` 的规则来源与修改方法。词表在 `assets/banned_words.txt`，每行 `级别|类别|词`，可按行业增删。

## 错误级（必须改）

| 类别 | 说明 | 改法 |
|---|---|---|
| 极限词 | 广告法禁止的绝对化用语：最好、第一、顶级、唯一、100% 等 | 换成具体事实：「我用过的三款里最顺手的」「回购了 3 次」 |
| 功效承诺 | 根治、治愈、无副作用、保证有效等 | 只描述个人体验和使用时长，不承诺结果 |
| 站外导流 | 微信、淘宝、二维码、手机号、外部链接 | 改为「主页」「评论区」等站内表达 |
| 虚假诱导 | 点赞抽奖、互粉、刷单 | 删除 |
| 长度 | 标题超 20 字、正文超 1000 字、标签超 10 个 | 删减 |

「第一次」「最近」「唯一的缺点」等正常搭配已加入白名单，不会误报。

## 警告级（建议改）

夸大表述（闭眼入、天花板、吊打）、AI 套话（综上所述、赋能）、缺少钩子、缺少互动引导、段落过长、正文没有具体数字。

## 脚本检查不了、需要人工判断的

- 医疗、保健、金融、教育培训等行业有额外资质要求，涉及时提醒用户自行确认。
- 商业合作需按平台规则标注。
- 不得冒充真实用户写虚假体验，不得生成虚假评论或刷量方案。
- 对比竞品时不贬低、不点名攻击。
- 平台规则会更新，词表只是底线，最终以小红书官方规则为准。
